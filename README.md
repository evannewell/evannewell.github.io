# Evan Newell's professional website

A simple static website for GitHub Pages. No build tools or external fonts are required.

## Publish

Create a public repository named `<your-GitHub-username>.github.io` and upload the contents of this folder to its root. Under Settings → Pages, choose Deploy from a branch, then `main` and `/ (root)`.

## Update

- Edit `index.html` to update the biography.
- Edit `teaching.html` to update teaching experience.
- Replace `Evan_Newell_CV.pdf` to update the CV, preserving the filename.
- Replace `headshot.jpg` to update the photo.
- Edit `style.css` to adjust the layout.

The headshot and CV are hosted locally so visitors do not need Google Sites or Google Drive access.
